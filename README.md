# Draft Arena

Русскоязычный аукцион персонажей для двух игроков на одном устройстве.

**[Открыть игру](https://khairikhanshr.github.io/anime-character-auction/)** — доступно всем, без регистрации и входа в аккаунт.

## Возможности

- Шесть тем по 24 персонажа с русскими именами и локально сохранёнными портретами: «Клинок, рассекающий демонов», «Блич», «Моя геройская академия», «Атака титанов», «Игра престолов», «Магическая битва».
- Одинаковый стартовый бюджет, имена игроков и размер команды от 1 до 12.
- Случайная колода без повторной продажи персонажей.
- Ставки от 0,01 игрового доллара. Все расчёты выполняются в целых центах.
- Покупка по наибольшей ставке; при равенстве — поочерёдный скрытый выбор в «камень, ножницы, бумага».
- Один цент резервируется на каждое оставшееся место в команде.
- Автоматическое сохранение партии в localStorage; адаптация под телефон и компьютер.
- Мягкие полупрозрачные панели и системный шрифт в стиле iOS/macOS. На телефоне — крупные кнопки, игроки друг под другом, прокручиваемые составы команд и закреплённая кнопка покупки.
- Каталог героев, поиск, просмотр команд и итоговый экран.
- Характеристики всех 144 героев, сила команды, итоговый победитель по сумме баллов и ничья при равенстве. Цена покупки на результат не влияет.

## Сравнение силы

В `dist/power.json` хранятся вручную выставленные **игровые оценки Draft Arena**, версия персонажа, краткая способность и ссылки на открытые справочники. Это авторская интерпретация описаний, а не официальные числовые характеристики или скопированный рейтинг. Редакция 1 от 20 октября 2026.

Четыре характеристики — атака, защита, скорость и техника — оцениваются от 1 до 25. Их сумма даёт от 4 до 100 баллов за героя. Сила команды равна сумме её героев; никакого дополнительного округления, случайности или зависимости от цены нет. При одинаковой сумме фиксируется ничья по силе.

Ориентиры шкалы: 1–5 — низкий уровень, 6–10 — базовый, 11–15 — опытный, 16–20 — высокий, 21–25 — элитный **внутри выбранной вселенной**. Баллы не являются физическими единицами: 80 не означает вдвое большую мощность, чем 40. Техника учитывает также тактику и поддержку, защита — восстановление. Система не моделирует конкретный бой, сочетания техник, контрприёмы и синергию.

Используются версии, явно указанные в карточках: основная манга и сериал HBO, без сиквелов. Например, Тандзиро — человек, Джейме — до потери руки, Гэто — не Кэндзяку. Учитываются личное снаряжение и призывы своей техники, но не армии, политическая власть, драконы Дейенерис или Гул Земли. Временные формы и специальные ограничения тоже подписаны. Возможны спойлеры способностей.

Основы описаний: [Demon Slayer](https://en.wikipedia.org/wiki/List_of_Demon_Slayer:_Kimetsu_no_Yaiba_characters), [Bleach](https://en.wikipedia.org/wiki/List_of_Bleach_characters) и [синигами](https://en.wikipedia.org/wiki/List_of_Soul_Reapers_in_Bleach), [My Hero Academia](https://en.wikipedia.org/wiki/List_of_My_Hero_Academia_characters), [Attack on Titan](https://en.wikipedia.org/wiki/List_of_Attack_on_Titan_characters), [Game of Thrones](https://en.wikipedia.org/wiki/List_of_Game_of_Thrones_characters), [Jujutsu Kaisen](https://en.wikipedia.org/wiki/List_of_Jujutsu_Kaisen_characters). Дополнительные профили и все ссылки доступны в карточках и разделе «Как считается сила». Справочники описывают способности; числовые оценки принадлежат этому проекту.

Во время игры справочники не загружаются. Если локальная таблица оценок недоступна или запись некорректна, аукцион продолжает работать, но неполная сумма не показывается и победитель не назначается. На итоговом экране можно повторить загрузку. Существующие сохранения совместимы: оценки вычисляются по ID героев, формат партии не менялся. Обновление каталога не перезаписывает `power.json`; для новых ID оценки нужно добавить вручную.

## Запуск

Нужен Python 3. В каталоге проекта:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Для запуска через npm: `npm start`.
Сборка и установка зависимостей не требуются. Открытие `index.html` напрямую через `file://` не поддерживается из-за загрузки JSON-каталога.

## Проверка

Node.js 20 или новее:

```sh
npm run check
```

Тесты проверяют расчёты в центах, ограничения бюджета и размера команды, повышение ставок, все исходы суефа, списание средств, сохранение, отсутствие повторов, полноту оценок и источников, точные суммы, победу и ничью, сбой загрузки оценок и совместимость сохранённых партий во всех шести темах.

## Публикация

Готовые статические файлы находятся в `dist/`. Их можно опубликовать на GitHub Pages, Cloudflare Pages или другом статическом хостинге. Все пути относительные, поэтому приложение работает и в подкаталоге репозитория.

Публичный сайт размещён на GitHub Pages из корня ветки `gh-pages`. После изменений в `dist/` сохраните их коммитом и обновите сайт командой `git subtree push --prefix=dist github gh-pages`.

## Данные и изображения

Подборка сделана в октябре 2026 года. Для пяти аниме взяты первые 24 героя соответствующей манги по количеству добавлений в избранное [AniList](https://anilist.co). Для «Игры престолов» вручную подобраны узнаваемые герои основного состава [TVmaze](https://www.tvmaze.com/shows/82/game-of-thrones).

Публичная ссылка на источник каждого персонажа сохранена в `dist/catalog.json`. Изображения загружены локально для надёжного показа; внешние API не вызываются во время игры. Используется системный шрифт устройства, без внешней загрузки шрифтов.

Обновление каталога: `python3 scripts/fetch-catalog.py`. Скрипт требует доступа к AniList и TVmaze. Русские имена хранятся в `scripts/translations.json`. Новые имена, которых нет в словаре, нужно перевести перед публикацией.

Это неофициальный некоммерческий фан-проект. Персонажи, названия и изображения принадлежат соответствующим правообладателям. Приложение не принимает платежи. Сетевой мультиплеер не предусмотрен: оба игрока используют одно устройство.
