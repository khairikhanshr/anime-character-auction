# Draft Arena

Русскоязычный аукцион персонажей для двух игроков на одном устройстве.

**[Открыть игру](https://khairikhanshr.github.io/anime-character-auction/)** — доступно всем, без регистрации и входа в аккаунт.

## Возможности

- Шесть тем по 24 персонажа с русскими именами и локально сохранёнными портретами: «Клинок, рассекающий демонов», «Блич», «Моя геройская академия», «Атака титанов», «Игра престолов», «Магическая битва».
- Одинаковый стартовый бюджет, имена игроков и размер команды от 1 до 12.
- Случайная колода без повторной продажи персонажей.
- Ставки от 0,01 игрового доллара. Все расчёты выполняются в целых центах.
- Покупка по наибольшей ставке; при равенстве — поочерёдный скрытый выбор в «камень, ножницы, бумага».
- Один цент резервируется на каждое оставшееся место в команде.
- Автоматическое сохранение партии в localStorage; адаптация под телефон и компьютер.
- Каталог героев, поиск, просмотр команд и итоговый экран.

## Запуск

Нужен Python 3. В каталоге проекта:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Для запуска через npm: `npm start`.
Сборка и установка зависимостей не требуются. Открытие `index.html` напрямую через `file://` не поддерживается из-за загрузки JSON-каталога.

## Проверка

Node.js 20 или новее:

```sh
npm run check
```

Тесты проверяют расчёты в центах, ограничения бюджета и размера команды, повышение ставок, все исходы суефа, списание средств, сохранение, отсутствие повторов и полную партию из 24 покупок.

## Публикация

Готовые статические файлы находятся в `dist/`. Их можно опубликовать на GitHub Pages, Cloudflare Pages или другом статическом хостинге. Все пути относительные, поэтому приложение работает и в подкаталоге репозитория.

Публичный сайт размещён на GitHub Pages из корня ветки `gh-pages`. После изменений в `dist/` сохраните их коммитом и обновите сайт командой `git subtree push --prefix=dist github gh-pages`.

## Данные и изображения

Подборка сделана в октябре 2026 года. Для пяти аниме взяты первые 24 героя соответствующей манги по количеству добавлений в избранное [AniList](https://anilist.co). Для «Игры престолов» вручную подобраны узнаваемые герои основного состава [TVmaze](https://www.tvmaze.com/shows/82/game-of-thrones).

Публичная ссылка на источник каждого персонажа сохранена в `dist/catalog.json`. Изображения загружены локально для надёжного показа; внешние API не вызываются во время игры. Шрифт Manrope загружается с Google Fonts, при отсутствии сети используется системный шрифт.

Обновление каталога: `python3 scripts/fetch-catalog.py`. Скрипт требует доступа к AniList и TVmaze. Русские имена хранятся в `scripts/translations.json`. Новые имена, которых нет в словаре, нужно перевести перед публикацией.

Это неофициальный некоммерческий фан-проект. Персонажи, названия и изображения принадлежат соответствующим правообладателям. Приложение не принимает платежи. Сетевой мультиплеер не предусмотрен: оба игрока используют одно устройство.
